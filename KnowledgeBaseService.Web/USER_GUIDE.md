# Vue3 Web UI 使用指南

## 快速开始

### 1. 安装并启动

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:5173
```

### 2. 导入文档

#### 单文件导入
- 进入"导入文档"页签
- 拖拽或点击上传 .docx, .pdf, 或 .md 文件
- 输入文档标题和分类
- 点击"开始导入"
- 监控上传和索引进度

#### 批量导入
- 选择"批量导入"页签
- 上传 1-10 个文件
- 点击"开始批量导入"
- 查看每个文件的进度

**支持的格式**:
- `.docx` - Microsoft Word 文档
- `.pdf` - PDF 文档
- `.md` - Markdown 文本文件

**限制**:
- 单文件最大 50MB
- 批量最多 10 个文件

### 3. 管理文档

在"文档列表"页面：

- **搜索**: 输入关键词搜索文档
- **分页**: 选择每页显示条数
- **查看**: 点击"查看"按钮查看文档详情
- **查询**: 点击"查询"自动跳转到对话页面
- **删除**: 点击"删除"移除不需要的文档

### 4. RAG 查询与对话

在"RAG 对话"页面：

#### 提问
1. 在输入框输入问题
2. 选择响应模式（普通/流式）
3. 按 Ctrl+Enter 或点击"提交查询"

#### 查看结果
- **答案**: AI 根据文档生成的回答
- **相关文档**: 显示来源文档和相关度评分
- **引用**: 知道信息来自哪些文档

#### 对话管理
- **复制**: 复制消息内容
- **删除**: 删除单条消息
- **清空**: 清空所有对话历史

## 性能提示

### 导入进度详解

导入过程分为三个阶段：

1. **上传阶段** (uploading)
   - 文件上传到服务器
   - 进度 0-100%
   - 耗时：取决于文件大小和网速

2. **索引阶段** (indexing)
   - 服务器处理文件并建立向量索引
   - 进度 0-100%
   - 耗时：约 8-15 秒（2MB 文件）

3. **完成** (completed)
   - 文档已准备好进行搜索和查询

### 查询优化

- 使用具体、详细的问题获得更好的结果
- 流式响应提供更快的初始反馈
- 相关度评分越高的文档越可靠

## 常见任务

### 导入一个 Word 文档
```
1. 在"导入文档"页面选择文件
2. 输入标题："技术手册"
3. 选择分类："技术文档"
4. 点击"开始导入"
5. 等待索引完成
```

### 查询关于某文档的内容
```
1. 进入"文档列表"
2. 找到对应文档
3. 点击"查询"按钮
4. 在"RAG 对话"页面输入问题
5. 查看答案和来源文档
```

### 批量导入多个 PDF
```
1. 进入"导入文档"页的"批量导入"
2. 上传 3 个 PDF 文件
3. 点击"开始批量导入"
4. 在进度列表中监控各文件状态
5. 成功后在"文档列表"中查看
```

## 故障排除

### 导入失败
| 症状 | 原因 | 解决方案 |
|------|------|--------|
| 上传失败 | 网络连接问题 | 检查网络，重试 |
| 文件过大 | 超过 50MB | 压缩或分割文件 |
| 格式错误 | 不支持的文件类型 | 使用 .docx, .pdf, .md |
| 索引超时 | 后端服务无响应 | 检查后端是否运行 |

### 查询无结果
| 症状 | 原因 | 解决方案 |
|------|------|--------|
| 无相关文档 | 索引未完成 | 等待索引完成后重试 |
| 结果不准确 | 搜索词不合适 | 修改搜索词 |
| 连接错误 | 后端不可用 | 确保后端运行在 5000 端口 |

### 页面加载缓慢
| 症状 | 原因 | 解决方案 |
|------|------|--------|
| 首次打开慢 | 依赖加载中 | 等待或清除缓存 |
| 文档列表慢 | 数据量过大 | 使用搜索过滤 |
| 对话响应慢 | 网络延迟 | 检查网络连接 |

## 后端连接

### 本地开发
```
前端: http://localhost:5173
后端: http://localhost:5000
```

后端启动方式：
```bash
cd KnowledgeBaseService.Api
dotnet run
```

### 生产部署
修改 `vite.config.ts` 中的代理配置：
```typescript
server: {
  proxy: {
    '/api': {
      target: 'https://your-api-server.com',
      changeOrigin: true,
    }
  }
}
```
