# PDF 智能识别功能说明

## 📋 功能概述

系统现已支持 **智能 PDF 处理**，能够自动识别 PDF 类型并选择最佳提取方案：

- ✅ **文本型 PDF**：直接提取文本层（快速、准确）
- ✅ **扫描版 PDF**：LibreOffice 转图片 + 豆包视觉识别（OCR 替代方案）
- ✅ **混合型 PDF**：智能判断，自动切换处理方式

## 🎯 处理流程

### 第一阶段：文本层提取

```
PDF 文件 → iTextSharp 解析 → 逐页提取文本 → 统计空页率
```

**输出示例**（文本型 PDF）：
```
[第 1 页]
这是第一页的内容...

[第 2 页]
这是第二页的内容...
```

### 第二阶段：智能检测

**判断条件**：
- 提取文本长度 == 0 → 100% 扫描版
- 空页率 > 80% → 图片型 PDF

**日志示例**：
```
[INFO] PDF 文档包含 32 页
[INFO] PDF 文本层提取完成，共 0 字符（空页: 32/32）
[INFO] 检测到扫描版 PDF（32/32 页无文本层），切换到视觉识别模式
```

### 第三阶段：视觉识别（仅扫描版）

```
PDF 文件 → 保存临时文件 → LibreOffice 转 PNG 图片（每页一张）
  → 豆包视觉逐页识别 → 合并所有页面内容 → 清理临时文件
```

**LibreOffice 命令**：
```bash
soffice --headless --convert-to png --outdir /tmp/images /tmp/document.pdf
```

**豆包识别提示词**：
```
提取这页 PDF 的所有文字内容、表格数据和关键信息。
用简洁的语言描述，便于检索。
```

**输出示例**（扫描版 PDF）：
```
[PDF 文档（扫描版）]
共 32 页

=== 第 1 页 ===
员工手册
2025 版
公司名称：有我科技

=== 第 2 页 ===
目录
第一章 公司介绍 ........................ 3
第二章 员工权益 ........................ 8
第三章 考勤制度 ........................ 15
...
```

## 🔧 故障排查

### 问题 1：LibreOffice 未找到

**错误信息**:
```
PDF 转图片失败: soffice: command not found
```

**原因**: Docker 镜像缺少 LibreOffice

**解决方案**:
```bash
# 检查 Dockerfile 是否包含 LibreOffice 安装
RUN apt-get update && apt-get install -y \
    libreoffice-core \
    libreoffice-draw \
    && rm -rf /var/lib/apt/lists/*

# 重新构建镜像
docker build -t knowledgebase-service:latest .
```

---

### 问题 2：PDF 转换无输出

**错误信息**:
```
PDF 转换未生成任何图片
```

**可能原因**:
1. PDF 文件损坏或加密
2. LibreOffice 不支持该 PDF 格式
3. 临时目录权限问题

**解决方案**:
```bash
# 进入容器测试
docker exec -it knowledgebase-service bash
soffice --headless --convert-to png /tmp/test.pdf

# 检查权限
ls -la /tmp/
chmod 755 /tmp/
```

---

### 问题 3：视觉识别超时

**错误信息**:
```
豆包视觉 API 调用超时（页码: 15/100）
```

**解决方案**:
1. **分批处理**: 将大文件拆分为多个小文件
2. **增加超时**: 在 `DoubaoVisionClient` 中设置更长的超时时间
3. **并发识别**: 修改代码支持多页并行识别（需控制并发数）

---

### 问题 4：识别准确度低

**现象**: 扫描版 PDF 识别内容错误率高

**可能原因**:
- PDF 分辨率太低（< 150 DPI）
- 图片质量差（模糊、歪斜）
- 特殊字体或手写文字

**建议**:
1. 使用高分辨率扫描（300 DPI+）
2. 确保图片清晰、对比度高
3. 手写文字建议使用专业 OCR 工具预处理

## 📈 性能优化建议

### 1. 并发识别（适用于大文件）

**当前实现**: 串行识别
```csharp
for (int i = 0; i < imageFiles.Count; i++)
{
    var pageContent = await AnalyzeImageAsync(...);
}
```

**优化方案**: 并行识别（需控制并发数）
```csharp
var tasks = imageFiles.Select((file, index) => 
    AnalyzeImageWithRetryAsync(file, index)
);
var results = await Task.WhenAll(tasks);
```

**预期提升**: 3-5 倍速度提升（受 API 并发限制）

**预期效果**: 重复上传秒级返回
