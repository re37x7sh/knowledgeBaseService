# 文档格式显示功能说明

## ✅ 已完成的改动

### 1. 数据库层 (Core)
- ✅ `Document.cs` - 添加 `FileExtension` 字段（VARCHAR(20)，可为空）

### 2. 应用层 (Application)
- ✅ `DocumentResponse.cs` - 添加 `FileExtension` 属性
- ✅ `CreateDocumentRequest.cs` - 添加 `FileExtension` 属性
- ✅ `DocumentService.cs` - 在所有方法中映射 `FileExtension` 字段：
  - `CreateAsync()` - 保存文件扩展名
  - `GetByIdAsync()` - 返回文件扩展名
  - `ListAsync()` - 列表中包含文件扩展名

### 3. API 层
- ✅ `DocumentsController.cs` - `ImportFromFile()` 方法提取并保存文件扩展名

### 4. 前端 (Web)
- ✅ `document.ts` - `DocumentResponse` 接口添加 `fileExtension?` 字段
- ✅ `DocumentList.vue` - 表格添加"格式"列，显示 `.docx`, `.pdf`, `.xlsx` 等标签

## 🎯 功能特性

### 显示效果
文档列表表格新增"格式"列，位于"分类"和"创建时间"之间：

| 文档标题 | 分类 | **格式** | 创建时间 | 状态 | 操作 |
|---------|------|---------|---------|------|------|
| 项目需求文档 | 需求 | `.docx` | 2025-11-24 | 已就绪 | ... |
| 数据报告 | 报表 | `.xlsx` | 2025-11-24 | 已就绪 | ... |
| 技术手册 | 文档 | `.pdf` | 2025-11-24 | 已就绪 | ... |

### 支持的格式
- `.docx` - Word 文档
- `.pdf` - PDF 文档
- `.md` - Markdown 文档
- `.txt` - 纯文本文档
- `.xlsx` - Excel 表格（新增）
- `.csv` - CSV 表格（新增）
- `.jsonl` - JSON Lines 文件（新增）

### UI 细节
- 有格式时：显示灰色信息标签（`el-tag type="info"`），如 `.xlsx`
- 无格式时：显示灰色文字"未知"（适用于老数据或直接创建的文档）

## 📊 数据库变更

### 自动迁移
项目使用 SqlSugar CodeFirst 模式，重启应用时会自动执行：
```sql
ALTER TABLE Document ADD FileExtension VARCHAR(20) NULL;
```

### 兼容性
- ✅ 新字段可为空，不影响现有数据
- ✅ 老数据格式列显示"未知"
- ✅ 新导入的文档会自动记录格式
