## 🔄 工作流程

### 场景 1: 编辑模式 (默认)
```
1. 点击 [➕ 创建新版本] 按钮
2. 系统自动加载当前版本内容到文本框
3. 用户在大型编辑区修改内容
4. 实时显示字数计数
5. 填写变更说明、标签、编辑者
6. 点击 [创建版本] 按钮
7. 后端创建新版本，数据库保存
8. 版本列表自动刷新
```

### 场景 2: 上传模式
```
1. 在创建版本模态框中切换到 [📤 从文件上传] 标签
2. 点击上传区或拖拽 .txt/.md 文件
3. 系统读取文件内容，自动填充到内容字段
4. 自动从文件名生成版本标题 (去除扩展名)
5. 可选：修改标题、填写变更说明等
6. 点击 [创建版本] 按钮
7. 后端创建新版本，数据库保存
8. 版本列表自动刷新
```
